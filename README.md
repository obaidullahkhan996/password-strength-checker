# Password Strength Checker 🔐

## About the Project
This is a simple Python project that checks the strength of a password based on different conditions. It helps users understand whether their password is weak, medium, or strong.

I created this project to improve my Python programming skills and practice using conditional statements and string methods.

## Features
- Checks password length
- Checks for uppercase and lowercase letters
- Checks for numbers
- Checks for special characters
- Shows the password strength based on the conditions

## Technologies Used
- Python 3

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

   ```bash
   python password_checker.py
   ```

4. Enter a password when prompted.
5. Check the result displayed in the terminal.
